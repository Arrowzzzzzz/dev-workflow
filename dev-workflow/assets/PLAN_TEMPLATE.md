# 实现方案模板 PLAN_TEMPLATE

> 场景 A（new-feature.md）阶段 3 与场景 B（bug-fix.md）第 3 步共用：复制下方区块，按字段逐项填写后提交用户确认。
> 场景 B 为轻量修复，可只填 1/2/3/5/7/8 字段（根因、改动清单、修复方式、影响面、测试计划、待确认项），其余字段填「不适用」。
> 规则：字段不得跳过；缺失信息向用户提问或标注 `【待确认】`，不允许臆造填充。
